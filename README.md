## 阅读与下载

源码与报告可在上述目录中直接浏览。`MANIFEST.csv` 提供文件路径、类型和 SHA-256 校验值。完整公开版压缩包见 [Releases](https://github.com/YiChiChen1106/undergraduate-coursework-archive/releases)。

## 公开范围与隐私处理

- 保留作者署名，遮去可检测到的学号、电话号码和邮箱地址。
- 可可靠脱敏的 PDF 保留原版式；Word 和 PowerPoint 文件提供脱敏文字稿，文字稿不保证保留公式、插图与原版式。
- 清除 Notebook 执行输出和附件，只保留可阅读的源单元。
- 不发布密钥、私人照片、商业软件安装包、模型权重、大型数据集、第三方课件与试卷。
- 扫描件、加密文件和不能自动确认脱敏效果的文件暂不发布。

包含完整原件的本地压缩档单独保存，没有上传到这个公开仓库。公开版不是全部原始资料的逐字节备份。

## 历史代码说明

部分课程代码依赖旧版 MATLAB、Python、FPGA 或电路仿真环境。归档过程未逐项运行课程项目，也未补齐外部数据集。文件按原课程结构保留，脱敏可能改变示例中的身份字符串。
