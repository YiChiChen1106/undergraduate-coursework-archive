# DSP

This directory preserves selected undergraduate coursework by YiChiChen.

Student identifiers and contact details have been redacted. PDF reports preserve their original layout where reliable text-layer redaction was possible. Editable Office documents are represented by privacy-safe Markdown transcripts; equations, figures and layout may not be reproduced in those transcripts.

Large datasets, model checkpoints, software installers, third-party reference material, private photographs and files requiring manual privacy review are retained only in the private local archive. The original documents are not deleted.

Historical code has not been rerun as part of this archival task. Relative data paths and older dependencies may need to be updated before use.
