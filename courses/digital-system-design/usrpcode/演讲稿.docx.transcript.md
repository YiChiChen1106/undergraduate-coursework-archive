Good morning everyone. My name is Yichi Chen, and today I’m excited to present my project titled "Software-Defined Radio-Based Transmitter-Receiver System with Timed Transmission for Human Activity Recognition." This project explores software-defined radio, or SDR, a technology that shifts radio functions from hardware to software, allowing for greater flexibility and adaptability. The specific focus of my project was on implementing timed transmission within this system, which has significant applications in fields like healthcare and IoT.

Slide 2: Project Aim

The primary aim of this project was twofold. First, I aimed to develop a reliable transmitter-receiver system using GNU Radio and USRP, focusing on precise timed transmission. Timed transmission is crucial in scenarios where the timing of the signal is critical, such as in monitoring human activities like walking, sitting, or even detecting falls in real-time. The ability to control the exact duration of a signal transmission can significantly improve the accuracy and reliability of such systems.

Second, I wanted to explore how SDR could be applied to human activity recognition (HAR). Human activity recognition is an area of growing interest, particularly for applications in healthcare and smart home environments. Traditional methods often rely on wearable devices or cameras, but these come with limitations such as user discomfort and privacy concerns. SDR offers a non-intrusive alternative, using radio waves to detect and classify activities without the need for additional devices on the user.

To summarize, this project aimed to merge these two goals: developing a precise and reliable SDR system and exploring its application in recognizing and monitoring human activities.

Slide 3: Methodology and Key Results

To achieve these objectives, I first set up a robust development environment. As a second-year student with no prior experience in SDR, this was a significant challenge. With guidance from my supervisors, Dr. Zakir and Dr. William Taylor, I set up GNU Radio on a virtual machine running Ubuntu. This involved configuring the network to establish communication between the USRP device and my computer—a process that required manual IP configuration and troubleshooting to ensure a stable connection.

Once the environment was set up, I moved on to the implementation phase. I wrote and tested two key Python programs. The first program established a basic transmitter-receiver system, managing signal generation, transmission, reception, and demodulation using various GNU Radio blocks. The second program introduced a critical enhancement: timed transmission. This program controlled the transmission duration, ensuring that signals were sent for exactly three seconds, which is vital for applications requiring synchronized data exchange.

Now, let’s talk about the results. After running these programs, I found that the system consistently transmitted and received signals across multiple subcarriers. The visual representation of the received signal data, as seen in the plots generated during testing, showed distinct patterns corresponding to different human activities. For example:

Empty Room: The baseline showed minimal fluctuations, as expected when no human presence was detected.

Leaning: There was a noticeable increase in variation, reflecting the subtle movement of leaning.

No Activity: Minimal variation was observed, slightly higher than the empty room but still consistent.

Sitting Down and Standing Up: These actions caused spikes in signal variation, reflecting the movement.

Walking: Both walking towards and away from the transmitter and receiver caused pronounced signal variability, with peaks and valleys reflecting the changes in proximity.

These consistent patterns across subcarriers indicate that the system can reliably detect and differentiate between various activities, which is crucial for real-world applications.
