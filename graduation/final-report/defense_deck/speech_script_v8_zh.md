目标时长：约 15 分钟  
项目题目：基于 nnU-Net 的细小视网膜血管分割研究

## 第 1 页：标题

各位老师、各位答辩委员会成员，大家上午好。我叫陈奕驰，今天我将介绍我的毕业设计项目，题目是“Research on Fine Retinal Vessel Segmentation Based on nnU-Net”。

本项目的核心主题是视网膜血管分割，尤其关注细小、弱响应血管分支的分割。在这项工作中，我并不是要替代 nnU-Net 这个通用框架，而是以 nnU-Net v2 作为一个较强的基线，研究面向该任务的结构改进是否能够进一步提升细血管恢复、血管连续性以及假阳性控制。

在这一页右侧，我展示了这个任务最基本的输入和输出形式：从原始眼底图像到血管分割结果。目标是生成一张更完整、更适合后续临床解释或定量分析的血管图。

## 第 2 页：临床意义与使用场景

在介绍方法之前，我想先说明为什么这个任务是有意义的。

眼底成像是一种非侵入式检查方式，可以观察眼内的微血管结构。这些血管结构与眼科疾病相关，同时也能间接反映一些全身性血管状况。但是，有临床价值的信息并不总是能直接从原始图像中清楚看出来，尤其是外周细小血管、血管连续性，以及一些细微的形态变化。

这一页展示的流程描述了一个更接近实际应用的场景。首先，从患者那里采集眼底图像；然后，血管分割模型提取血管树，生成结构化的血管图。基于这张血管图，后续的计算机辅助诊断模块可以提取定量血管特征，例如血管口径、弯曲度、分支模式，以及与动静脉相关的指标。这些特征可以支持风险评估或疾病提示。

因此，这个项目的实际价值并不是让模型直接给出最终诊断。相反，它改进的是一个重要的中间环节。更完整、更可靠的血管图可以让下游特征提取和临床复核更加稳定。最终解释、与患者沟通，以及治疗或随访决策，仍然应该由医生主导。

## 第 3 页：细小血管分割的任务挑战

细小视网膜血管分割有几个方面的挑战。

第一，外周细血管通常对比度较低。在原始图像中，这些血管可能很弱，并且部分被背景纹理遮挡。虽然对比度增强可以让血管更清楚一些，但仅靠预处理并不能解决完整的分割问题。

第二，视网膜血管不是简单的直线结构。它们包含弯曲分支、分叉点、局部断裂，以及非常小的末端结构。因此，模型不仅需要捕捉局部像素外观，还需要保持结构连续性。

第三，敏感性和精确率之间存在权衡。如果模型变得更敏感，它可能会恢复更多细血管，但也可能引入分散的假阳性。如果模型过于保守，输出看起来会更干净，但弱分支可能会被漏掉。

最后，nnU-Net 本身已经是一个很强、很成熟的基线。这意味着简单堆叠模块不太可能带来可靠提升。因此，本项目的核心研究问题是：在 nnU-Net 之上，什么样的结构改动仍然能够带来有用的增益？

## 第 4 页：基线与整体技术路线

这一页总结了项目的实验路线。

第一阶段是建立基线。我使用 2D nnU-Net v2 作为受控参考，patch size 为 512×512。我也探索了一些初步修改，例如 CLAHE 预处理和 Focal Loss。这些变化会影响训练行为，但没有带来稳定的最终提升。

第二阶段关注结构迁移和筛选。我把 PA-Net 中的一些思想迁移到 nnU-Net 设置中，尤其是 LPT 和 AFFM。之后，我保留 LPT 路线作为主线，并测试了 deformable sampling、多尺度聚合、Coordinate Attention 和 Dynamic Snake Convolution。

第三阶段关注输出精修和结果分析。由于高敏感性的模型可能产生孤立的假阳性区域，我使用了轻量的连通域后处理。模型比较时使用的指标包括 sensitivity、precision、specificity、accuracy 和 F1-score。

对于后期的结构实验，我使用统一的五折验证协议。这一点很重要，因为它让不同模块之间的比较更有意义。

## 第 5 页：PA-Net 迁移与模块筛选

第一个结构实验是 PA-Net 迁移和模块筛选。

表格显示，直接迁移完整的 PA-Net 设计在当前设置下并不有效。与 nnU-Net 基线相比，完整 PA-Net 版本提高了 precision，但 sensitivity 明显下降，F1-score 从 0.7891 降到了 0.7782。这说明完整迁移让模型变得更保守，不太适合恢复弱血管分支。

接着我测试了单模块变体。LPT Only 的 F1-score 为 0.7935，AFFM Only 的 F1-score 为 0.7942。这些提升并不大，但相比完整 PA-Net 迁移更加稳定。

这一页的关键结论是：简单堆叠模块是不够的。后续设计不应该保留完整 PA-Net 结构，而应该保留以 LPT 为中心的路线，因为它更接近瓶颈层的结构建模，也更适合进一步针对细血管分割进行改造。

## 第 6 页：LPT、可变形采样与多尺度建模

经过筛选阶段后，项目进入 LPT 主线。

原始 LPT 模块使用固定的高层交互方式。但是，视网膜血管是弯曲且细长的，所以固定采样可能无法很好地贴合血管几何形状。为了解决这个问题，我测试了 deformable sampling，也就是通过偏移量让采样位置能够适应局部血管结构。

在实验中，4-point deformable LPT 将 F1-score 提升到 0.7958。这说明自适应采样对该任务是有帮助的。我也测试了 modulation，它增强了模型检测血管的倾向，但可能降低 precision。这再次体现了 sensitivity 和 precision 之间的权衡。

随后我引入了多尺度建模。它的思想是把浅层细节和深层语义信息结合起来，使模型能够在局部细血管细节和更大范围的结构上下文之间取得平衡。总体来看，这一阶段说明，面向血管的采样和多尺度信息比直接迁移完整模块更有前景。

## 第 7 页：Coordinate Attention 与 Dynamic Snake Convolution

这一页介绍了最终保留下来的两个重要结构思想：Coordinate Attention 和 Dynamic Snake Convolution。

Coordinate Attention 加入了方向感知的位置重标定。在视网膜血管分割中，位置和方向都很重要，因为血管是细长结构。Coordinate Attention 有助于网络在多尺度聚合之后强调更有信息量的空间响应。

Dynamic Snake Convolution 提供了另一种归纳偏置。它不是把卷积视为刚性的局部操作，而是使用一种类似轨迹的采样模式，更适合细长、弯曲的目标。这一点对于细小视网膜血管尤其相关，因为血管路径上的连续性非常重要。

实验中观察到的效果是 sensitivity 明显提高，也就是模型恢复了更多血管像素。但是，在一些设置下 precision 会下降，说明假阳性也增加了。因此，这一阶段提升了细血管恢复能力，但也让假阳性控制变得更加重要。

## 第 8 页：后处理与 clDice 探索

在 MS-DSConv 和 Coordinate Attention 之后，剩下的主要问题是输出精修。

最终保留的精修方法是连通域过滤。它的思路很简单：非常小的孤立连通区域更可能是假阳性，而不是真实血管结构。在最终保留的设置中，阈值 X 等于 20。这个轻量的后处理步骤减少了小的孤立噪声，并将最终 F1-score 提升到 0.8027。

我也探索了 clDice，因为它强调拓扑结构和类似骨架的结构，看起来适合血管分割。但是，在具有代表性的 X=20 设置下，clDice 在某些情况下提高了 sensitivity，却降低了 precision 和 F1-score。因此，它被作为探索内容，但没有保留在最终方案中。

这一页说明了一个重要观点：单纯提高 sensitivity 是不够的。对于这个任务，最终输出必须在细血管恢复和假阳性抑制之间取得平衡。

## 第 9 页：定量结果

这一页总结了统一后期实验设置下的定量结果。

nnU-Net 基线的 F1-score 是 0.7891。完整 PA-Net 迁移下降到 0.7782，这确认了直接迁移并不适合当前任务。Deformable LPT 将结果提升到 0.7958。之后，多尺度和注意力相关变体进一步推动了性能提升。

最终保留的方案结合了 MS-DSConv、Coordinate Attention，以及 X=20 的轻量连通域后处理，最终 F1-score 达到 0.8027。相比后期 nnU-Net 基线，这是 0.0136 的绝对 F1 提升。

最终 sensitivity 和 precision 分别为 0.8059 和 0.8035。这说明最终方案并不是单纯提高检测倾向，而是把输出拉回到了一个更平衡的状态。

我会把这个提升描述为“幅度不大，但有意义”。说它幅度不大，是因为 nnU-Net 已经很强，绝对增益并不大；说它有意义，是因为这个提升遵循了一条一致的技术路线，并且是在相同的比较协议下得到的。

## 第 10 页：定性结果

定性结果可以帮助解释数值表现。

在具有代表性的样例中，基线预测相对干净，但它经常漏掉弱的、细小的血管分支。这与保守预测模式是一致的。

后期模型，尤其是 MS-DSConv 加 Coordinate Attention 的设计，恢复了更多连续分支和更多细血管结构。在一些局部区域中，血管图变得更完整，连通性也更好。

但是，这些定性结果也说明了为什么需要后处理。当模型变得更敏感时，它可能会产生孤立噪声。连通域过滤有助于减少这种分散噪声，同时不会过度改变主要血管结构。

因此，定性解释与定量结果是一致的：最终方法提升了细血管恢复能力，但这种提升需要通过输出精修来控制。

## 第 11 页：局限性与未来工作

这个项目仍然有几个局限性。

第一，验证范围仍然限制在本研究使用的公开基准条件下。这意味着当前结果不能直接被解释为临床鲁棒性的证明。

第二，假阳性控制仍然部分依赖基于规则的后处理。虽然这种方式有效且轻量，但更理想的方向是把更多控制能力转移到模型本身或训练目标中。

第三，DSConv、Coordinate Attention 和多尺度交互背后的机制仍然需要更深入的可解释性分析。实验显示它们有有用的行为，但还需要更多分析来解释每个模块在何时、为何起作用。

最后，一些细小分支和低响应区域仍然很难处理。这是可以预期的，因为最弱的血管接近解剖结构和图像噪声之间的边界。

未来工作方面，我会测试来自不同设备、不同病理情况和不同标注风格的更广泛数据。我也会更具体地分析 nnU-Net 预处理流程在眼底图像中的作用，探索可学习的假阳性控制方法，并用更接近临床场景的证据来评估方法。

## 第 12 页：总结与问答

总结来说，本项目在 nnU-Net 框架内找到了一条针对细小视网膜血管分割的、幅度不大但较稳定的改进路径。

最终保留的方案是 MS-DSConv 加 Coordinate Attention，并在输出端加入轻量连通域后处理。最终 F1-score 是 0.8027，而基线值是 0.7891。

本项目的主要贡献不是某一个很大的性能跳跃，而是一条受控实验路线：从 nnU-Net 出发，筛选迁移模块，细化以 LPT 为中心的结构，提升面向血管的建模能力，最后平衡 sensitivity 和假阳性控制。

总体来看，研究表明，细小视网膜血管分割受益于尊重血管连续性的结构建模，也受益于谨慎的输出精修。同时，该方法仍然属于研究阶段的改进，在任何临床使用前都需要进一步验证。
